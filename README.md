# Quote Skill Builder

Builds your company's own Claude skill for writing quotes: your layout, your logo, your wording. After that, anyone on the team can ask Claude for a quote and it starts from the same page.

**Who it is for:** Owners and sales leads whose team sends quotes that all look different.

**What you need:** Claude Code or Codex to run the builder, your best past quote, your logo, and your standard wording. To use the finished skill in the Claude app, code execution has to be on.

## Install

Open `SETUP-PROMPT.md`, copy the prompt in it, and paste it into a new Claude Code or Codex chat. It installs this skill and starts it. It keeps your existing skills as they are.
